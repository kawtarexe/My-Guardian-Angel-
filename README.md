# ୨୧ Guardian Angel

*a little visual novel made with Ren'Py ♡*

## ♡ About the game

Guardian Angel is a visual novel about an ordinary kid, their family, and the little moments of everyday life. The story begins in a quiet house at night while the kid's parents are busy with their own things.

This is my first time making a visual novel, so I'm still learning as I go!

## ♡ How I made it

- **Ren'Py** — for creating the game and writing dialogue.
- **Python / Ren'Py Script** — for the game's code and interactions.
- **Visual Studio Code** — for editing my scripts.
- **GitHub** — for sharing my project.

I learned by experimenting, testing things, and figuring stuff out when something didn't work.

## ୨୧ What I learned

I learned how to create characters, add backgrounds, write dialogue, position sprites, and organize my game files. I also got more familiar with fixing errors in my code.

## ♡ What was difficult?

Fixing errors was probably the most frustrating part. I also struggled with positioning characters correctly and making sure everything worked as expected. Sometimes even a small mistake could stop the game from running, so I had to test things a lot.

I'm still learning, but I'm happy I got to make something of my own!
